# Portfólio de Matheus Lobato

Versão estática preparada para publicação no GitHub Pages.

## Como publicar

1. No GitHub, crie um repositório público chamado `MatheusLobDev.github.io`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Abra `Settings` e depois `Pages`.
4. Em `Source`, escolha `Deploy from a branch`.
5. Selecione a branch `main`, a pasta `/ (root)` e clique em `Save`.
6. Aguarde alguns minutos e acesse `https://matheuslobdev.github.io`.

Para atualizar o site depois, edite o conteúdo de `index.html` ou os estilos em `styles.css` e envie as alterações ao mesmo repositório.
